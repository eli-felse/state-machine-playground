Definition

Syntax help
  • stateA -> stateB — a transition with no event label
  • stateA -> stateB : eventName — a transition triggered by an event
  • initial: stateName — explicitly mark the initial state
  • # comment or // comment — ignored lines
  • A line with just a name (e.g. idle) declares an isolated state
